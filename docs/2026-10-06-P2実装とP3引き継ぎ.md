## 次にやること：P3 収集・継続（§9 §10）
計画は承認済み。次の順で進める。

1. **コイン**: スコア÷100（ボーナスタイム中の分は ×2 ＝ `(score + bonusScore) / 100`）。`GameStats.bonusScore` は P2 で記録済み。`utils/progression.ts` の `grantPlayRewards` に足し、リザルトとタイトルに表示。ボーナスのカットインの文言を「スコア・コイン ×2」に直す
2. **ガチャ**（新規 `utils/gacha.ts`、`components/GachaScreen.tsx`）: 1回 100コイン、N60/R30/SR8/SSR2 を画面に表示、30回で SR 以上確定（`gacha.pityCount`）、重複はかけら +1、かけら10個で好きな未入手アイテムと交換
3. **図鑑**（新規 `components/CollectionScreen.tsx`）: カテゴリ別の収集数、未入手はシルエット、装備の切り替え
4. **装備の反映**（4カテゴリ × 6種。初期装備の4つは最初から持っている）
   - 衣装: ラビッドパの色ちがい。`Rabidopa.tsx` の内側の div に CSS の `hue-rotate` をかけるのが最小（外側は `rb-aura-*` が filter を使っているので内側に）。または `utils/rabidopaRig.ts` の `PALETTE` を差し替える
   - 打鍵エフェクト: `EffectCanvas.tsx` の `pick(RAINBOW)` の色表を差し替える
   - 効果音パック: `audioManager.playTypeNote` の波形（triangle / square など）を切り替える。スキルの「音階」とは別物
   - 背景: `DopaBackground.tsx` の `.dopa-bg` に配色違いのクラスを足す
   - 装備は多くの画面で使うので、props で配るより小さなモジュール（今の装備を返す関数）にする案
5. **デイリーミッション**（新規 `utils/daily.ts`）: 1日3つ、ローカル日付で更新（日付から決まる選び方にする）。`GameStats` の maxCombo / goldenCleared / perfectWords / correctChars / feverCount / score から進み具合を計算。報酬はコイン or EXP、全達成ボーナス、連続日数と7日ごとのごほうび。タイトルとリザルトに表示
6. **休けいお知らせ**（新規 `utils/breakTimer.ts`）: OFF/15/30/45/60分（初期 30分、`settings.breakMinutes` は保存データに用意済み）。プレイ終了後のリザルトでだけ出す。オプション画面に設定を足す（`ChoiceRow` は文字列の値が前提）
7. `docs/spec.md` §0・§13、`LEARNINGS.md` を更新

保存データの項目（`inventory` `equipped` `gacha` `daily` `player.coins` `player.shards`）は P2 で `utils/saveData.ts` に用意済み。書き換えは `mutateSave(fn)` を使う。
