# Gemini での素材づくりの学び

`LEARNINGS.md` から切り出した項目です（2026-10-06）。Gemini の Web 画面で画像・曲を作るときに読みます。手順の正本は `.claude/skills/gemini-assets/SKILL.md`。
書き方は LEARNINGS.md と同じ（1項目 1〜3行、太字で主張を先頭）。新しく学んだことはここに足します。

- **Gemini の背景画像は「1枚ごとに新しいチャット＋全部入りのプロンプト」で作る。モデルは Pro。** 同じチャットで題材だけ変えると前の絵（ビル）を引きずり、2回直しても消えなかった。「上に文字が乗る」と書くと絵に文字を描かれるので、「中央から上は広く空ける」とだけ書く。2752x1536 の JPEG で落ち、目に見える透かしはなかった。プロンプトは `docs/assets.md`。変換は `node scripts/convert-bg.mjs`（sharp。`_inbox/bg_*_src.*` → `public/assets/images/bg/*.webp`）。
- **透過したい絵は「真っ白な単色の背景＋絵の外がわを濃い太い縁で囲む」で頼み、`node scripts/convert-cutout.mjs <入力> <出力.webp> <幅>` で切りぬく。** ふちからつながった白だけを消すので、絵の中の白（ステッカーの白ふち、白い文字）は残る。タイトルロゴはこの方法で1回で通った。Gemini（Pro）は日本語9文字のロゴを、文字を1つずつ説明すれば正しく描けた。
- **Gemini の画面を開きなおした直後の「クリック → 入力 → Enter」は、1回めが届かないことがある。** 送信後にスクリーンショットで自分の発言が出ているか確かめ、出ていなければ同じ操作をもう一度送る。
- **Gemini の BGM は「音楽を作ってください。」で始める短めのプロンプトで頼み、ダウンロードは「トラックをダウンロード」→「音声のみ MP3」。** 1曲に1〜2分（長いと7分）かかる。BPM や構成を細かく書いた長いプロンプトは、エラーと「音声は出せないので設計図を書きました」で2回失敗した。落ちてくるのは 192kbps の MP3 で、長さは 65〜180秒とまちまち（指定しても守られない）。ファイル名は曲名になることがある（大きさが同じでも別の曲。ハッシュで確かめた）。長すぎる曲は `node scripts/trim-mp3.mjs <入力> <出力> <秒>` で頭だけ切りだす。
- **Gemini への入力は、入力欄（`.ql-editor`）に focus して `document.execCommand('insertText', false, 本文)` で流しこみ、送信ボタン（aria-label「プロンプトを送信」）を JS で click すると確実。** `computer` の type では、半角の英数字と記号（「1」「B」「#0B0320」「: 」）だけが抜けて届くことがあった（IME の状態しだい）。抜けると色指定も文字指定も消え、「B」を頼んだのに「A」が返った。1枚 60〜70秒。
- **ランクのバッジのような「文字入りステッカー」は、ロゴと同じ頼み方（白背景＋紺の太い縁、文字は1つずつ指定、1枚ごとに新しいチャット）で 7枚とも1回で通った。** 絵から離れた小さな星やきらめきも、縁で囲まれていれば `convert-cutout.mjs` で残る。
- **小さな絵をいくつも作るときは「2×2 のシート1枚」で頼み、`node scripts/split-sheet.mjs <入力> <出力の頭>` で4つに切ってから `convert-cutout.mjs` に渡す。** エフェクト6種（24個）が6枚・各1回で通った（1枚 50〜60秒、2048x2048）。「おたがいに大きく間をあける・くっつけない・ます目の線は描かない」と書くと、まん中で切っても欠けなかった。同じ文をくり返し送るときは、決まり文句を `sessionStorage` に入れておくと、新しいチャットを開いても使いまわせる。
- **Gemini の画面を開きなおした直後は、入力欄に半角スペースを1つ打ってから本文を打つと、1回めから届く。**（前に書いた「1回めが届かない」の回避策）
- **Gemini の画像のダウンロードボタンを JS の `click()` で押すと、2回めからそのタブではダウンロードが届かなくなる（画面には「ダウンロードしました」と出る）。** Chrome が「操作なしの連続ダウンロード」を止めるため。新しいタブで開きなおし、`computer` の left_click（座標）で押すと届く。ボタンの位置は返事の文の長さで変わるので、毎回スクリーンショットで確かめる（外すと画像の拡大表示が開く）。
- **【重大】ダウンロードフォルダから「いちばん新しい Gemini_Generated_Image_*.jpg」を取るときは、必ず日時でしぼる（`find -newermt "きょうの時刻"`）。** ダウンロードが届いていなかったとき、`ls -t | head -1` がユーザーの古い別のファイルをつかみ、`_inbox/` に動かしてしまった（すぐ元の名前で戻した）。新しいファイルがちょうど1つのときだけ動かす。
- **Chrome のタブグループの最初のタブを閉じると、残りのタブがグループから外れて操作できなくなる。** `tabs_context_mcp`（createIfEmpty）で作りなおす。外れたタブは開いたまま残るので、ユーザーに伝える。
- **Gemini の音楽生成は「5秒くらいのジングル」と頼んでも 60〜70秒の曲を返す。** ランク発表は頭の 8.3秒に区切りがあって使えたが、レベルアップ用は最初の区切りが 7.3秒で、ランク発表のジングルと重なるので見送った（`_inbox/jingle_levelup_src.mp3`）。短い効果音は合成のままがよい。
- **Gemini の画像のダウンロードは、押したあと 15秒は何もせずに待つ（JS の実行もページ移動もしない）。押す前に必ず hover してスクリーンショットを撮りなおす。** 押した直後に JS を実行して 9秒でページを移ったら届かず、ウィンドウの大きさが途中で変わって（1443→1469px）前の座標では外れた。届いたかは毎回 `find -newermt` で数える。
