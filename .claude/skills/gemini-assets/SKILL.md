# Gemini で素材を作る手順

## 大原則
- **Gemini は Web 画面（https://gemini.google.com/）をブラウザ操作して使う。Gemini API は使わない。** API キー・`.env`・SDK をプロジェクトに追加しない。他社の生成 API・生成サービスへも勝手に切り替えない。
- ブラウザ操作は Claude in Chrome（ユーザーの Chrome、Google にログイン済み）で行う。使えない場合は、作業を止めてユーザーに伝える。
- 1回のセッションで作る素材は、計画で列挙したものだけにする。

## 手順
1. **計画**: 作る素材を一覧にして、用途・サイズ・形式・置き場所を決め、ユーザーの承認を得る。`docs/assets.md` に同じ素材がないか先に確認する。
2. **Gemini を開く**: 新しいタブで https://gemini.google.com/ を開く。ログインしていなければユーザーに頼む（パスワードは扱わない）。
3. **生成**: 下の「プロンプトの型」で依頼する。キャラ関連は `docs/character/reference.jpg` か `docs/character/preview.png` を添付して、絵柄を揃える。
4. **取得**: ダウンロードしたファイルはまず `_inbox/`（git 管理外）に置く。
5. **確認**: 画像は開いて見る。次のどれかがあれば不採用にして作り直す。
   - 絵柄・色がラビッドパと揃っていない
   - 文字・ロゴ・既存キャラクターに似たものが入っている
   - 目に見える透かしが入っている（採用前にユーザーに相談）
6. **加工**: 必要なら手元で加工する（Python + Pillow などのローカル処理は可）。
   - 背景透過: Gemini には単色背景（例: 真っ白 #FFFFFF やクロマキー緑 #00FF00）で出させ、手元で抜く
   - サイズ: 表示サイズの2倍まで縮小し、PNG（透過あり）か WebP にする
7. **配置**: `public/assets/images/<種類>/` または `public/assets/sounds/<種類>/` に置く。ファイル名は英小文字のスネークケース（例: `bg_fever_rainbow.webp`、`sfx_combo_up.mp3`）。
8. **記録**: `docs/assets.md` の台帳に1行追加する（ファイル、用途、作成日、使ったツール・モデル名（画面に出ている名前）、プロンプト全文、加工内容）。プロンプトを残すのは、あとで同じ絵柄で作り直せるようにするため。

## プロンプトの型（画像）
```
子ども向けタイピングゲームの素材。
用途: <何に使うか>
絵柄: 太めの濃いアウトライン、フラットな塗り、丸みのある形、明るくポップ。添付画像のキャラクターと同じ絵柄。
色: メインのピンク #F7A8C4、影 #EC89AE、明部 #FDE1EB、線 #7A2E55。アクセントは黄色 #FFD600・青 #2962FF。
構図: <構図>
背景: 真っ白な単色（あとで透過するため）
文字やロゴは入れない。
```

## サウンド
- 効果音は既存の `utils/audioManager.ts` が Web Audio で合成している。素材ファイルにするのは、合成では出しにくい音（声・ジングル・BGM など）に限る。
- Gemini の Web 画面で音声・音楽を作れるかは、使う時点の画面で確認する。作れない場合や品質が足りない場合は、他の手段に切り替えずユーザーに相談する。
- 形式は MP3 か OGG。音量は揃えてから置く。
